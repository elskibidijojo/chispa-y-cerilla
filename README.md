# Chispa y Cerilla

Juego de acción estilo dibujo animado de los años 30, hecho con Claude. Se juega en el navegador: https://elskibidijojo.github.io/chispa-y-cerilla/

La música son grabaciones de jazz de los años 20 en dominio público (Internet Archive, colección 78rpm) y pistas libres de Kevin MacLeod (incompetech.com, CC BY 4.0).
